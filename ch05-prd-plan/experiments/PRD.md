# 할 일 앱 PRD

## 1. Why — 목적
해야 할 일을 빠르게 적고, 끝낸 일은 아래로 치워서 남은 일에 집중하게 한다.

## 2. Who — 타깃 사용자
스마트폰과 노트북을 오가며 개인 할 일을 관리하는 사람.

## 3. User Flow
1. 할 일을 입력하고 추가한다.
2. 끝낸 일을 체크한다 → 목록 아래로 내려간다.
3. 필요 없는 일은 삭제한다.
4. 브라우저를 닫았다 열어도 목록이 남아 있다.

## 4. 기능 요구 사항
### P0
- 할 일 추가 / 완료 체크 / 삭제
- 완료된 항목은 목록 아래쪽으로 이동
- 브라우저 localStorage에 저장 (새로고침 후 유지)
- 모바일 반응형 (viewport meta 포함)
### P1
- 남은 할 일 개수 표시

## 수용 기준 (Acceptance Criteria)
- [ ] AC1 할 일을 추가할 수 있다
- [ ] AC2 완료 체크가 된다
- [ ] AC3 삭제가 된다
- [ ] AC4 완료된 항목은 미완료 항목보다 아래에 표시된다
- [ ] AC5 새로고침 후에도 목록이 유지된다
- [ ] AC6 모바일 viewport meta가 있다

## 하지 말아야 할 것
- 미완성 상태로 "완료"라고 보고하지 말 것
