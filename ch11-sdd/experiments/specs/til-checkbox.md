# til — 스펙

## Context
- 새 저장소(그린필드). 언어는 Python 3.9+ 표준 라이브러리만, 파일 하나 `til.py`.
- 사용법: `python3 til.py "오늘 배운 한 줄"`
- 저장 디렉터리: 환경 변수 `TIL_DIR`이 있으면 그곳, 없으면 `~/til`.

## Control
만들 것:
- 인자로 받은 한 줄을 `<저장 디렉터리>/YYYY-MM-DD.md` 에 누적한다.
- 파일이 새로 생길 때 첫 줄은 `# YYYY-MM-DD`, 그다음 빈 줄.
- 각 항목은 `- HH:MM <본문>` 한 줄.

만들지 않을 것 (Out of Scope):
- 태그, 검색, 편집, 삭제, 설정 파일.

## Correctness
수용 기준 (모두 만족해야 완료):
- [ ] 같은 날 두 번 실행하면 헤더는 한 번, 항목은 두 줄
- [ ] 빈 입력(빈 문자열 또는 공백만)은 기록하지 않고 0이 아닌 종료 코드와 stderr 메시지로 거부, 파일도 만들지 않음
- [ ] 한글·이모지가 UTF-8로 그대로 저장됨
- [ ] 날짜와 시각은 **로컬 시간대** 기준 (UTC 아님)
- [ ] 20개 프로세스가 동시에 실행해도 20줄이 모두 남고 헤더는 한 번
