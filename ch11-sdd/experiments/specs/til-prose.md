# til — 스펙

## Context
- 새 저장소(그린필드). 언어는 Python 3.9+ 표준 라이브러리만, 파일 하나 `til.py`.
- 사용법: `python3 til.py "오늘 배운 한 줄"`
- 저장 디렉터리: 환경 변수 `TIL_DIR`이 있으면 그곳, 없으면 `~/til`.

## 설명
인자로 받은 한 줄을 저장 디렉터리의 `YYYY-MM-DD.md`에 누적하는 도구다. 파일이 새로 생길 때 첫 줄은 `# YYYY-MM-DD`이고 그다음 빈 줄이며, 각 항목은 `- HH:MM <본문>` 한 줄로 쓴다. 같은 날 여러 번 실행하면 헤더는 한 번만 있고 항목이 쌓여야 한다. 빈 문자열이나 공백만 있는 입력은 기록하지 않고 0이 아닌 종료 코드와 stderr 메시지로 거부해야 하며 이때 파일도 만들지 않는다. 한글과 이모지는 UTF-8로 그대로 저장한다. 날짜와 시각은 UTC가 아니라 로컬 시간대 기준이다. 여러 프로세스가 동시에 실행해도 줄이 사라지거나 헤더가 두 번 생기면 안 된다. 태그·검색·편집·삭제·설정 파일은 이번 범위가 아니다.
